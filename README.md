# Plateforme de gestion immobilière — Burkina Faso

Registre de gestion locative multi-agences, avec vitrine publique, pour les agences de Ouagadougou et Saaba.

- `CLAUDE.md` : règles du dépôt (à lire en premier).
- `docs/` : cadrage, décisions, lots, interrupteurs de fonctionnalités, journal des lots.
- `prompts/` : un prompt par lot.
- `maquette/` : maquette cliquable du lot 00 (sans backend). Voir `maquette/README.md` et `maquette/GUIDE-ENTRETIEN.md`.
